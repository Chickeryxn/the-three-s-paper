# Q4 最终方法说明

> 本文是 Q4 的**权威方法说明**，供论文写作与 solution package 引用。来源：方法卡、决策账本、代码计划、最终结果与稳健性证据。
> 模型契约哈希：`f6ef7af5819f339c4676d271a52ab59ff379239d8ee7999de215d0239ee6acba`（`planning/model_contract.json`）

## 1. 模型对象与控制方程

圆柱形中药材，初始半径 R₀ = 2.000 cm、长 25 cm，半径按附件2 收缩到 R_min = 1.198 cm（收缩 40.1%）。采用**一维径向轴对称**（决策 `g_framing_spatial_dimension`），在**归一化坐标 ξ = r/R(t)** 下求解。

令 \xi = r/R(t)，则

$$\left.\frac{\partial C}{\partial t}\right|_{\xi}=\frac{1}{\xi R^2}\frac{\partial}{\partial \xi}\left(D\,\xi\,\frac{\partial C}{\partial \xi}\right)+\underbrace{\frac{\xi\dot R}{R}\frac{\partial C}{\partial \xi}}_{\text{表观对流项}}$$

能量方程同形（系数换成 \alpha = k/(\rho c_p)）。**表观对流项完全已知**：\dot R 由附件2 的 PCHIP 单调插值解析求导得到，因此无需重构网格。

边界：\xi=1 处第三类对流；\xi=0 处对称。**初始条件** T = 28 °C、C = 2.55 kg/kg。

**物性（附录4）**：\rho = 760 + 90C、c_p = 1850 + 2150C/(C+1)、k = 0.12 + 0.20C/(C+1)、D = 4.2×10⁻⁴·exp(−0.30/C)·exp(−3850/T)。h = 25 W/(m²·K)、h_m = 8×10⁻⁷ m/s（决策 `g_framing_convective_coefficients`）。

**环境驱动**：预热阶段取附件1 实测序列（线性插值，t = 100 s 非采样点）；恒温干燥阶段按决策 `g_framing_env_extrapolation` 维持 T\infty = 50 °C、C\infty = 0.05 kg/kg。

## 2. 数值方法

**空间**：**顶点（节点）有限体积**（对偶控制体、守恒通量形式）作用于 ξ 坐标。节点 \xi_j = j\Delta\xi；对偶控制体在 ξ 坐标下的权重固定（w₀ = \Delta\xi²/8、w_j = j\Delta\xi²、w_N = (1−(1−\Delta\xi/2)²)/2），其和恒等于 ∫₀¹ξdξ = 1/2。面系数 cd_f = \xi_f·co/(\Delta\xi·R²)。ξ=0 的内侧面半径为 0，**轴对称条件由格式自动满足**；ξ=1 是原生节点，**表面水分浓度是直接未知量**，不经回算。

**表观对流**：按弱形式离散，面项 \frac12 k_c \xi_f²(y_j+y_{j+1})、体项 −2k_c w_j y_j、边界项 +k_c y_N，其中 k_c = \dot R/R。三项组合使**线性剖面被精确输运**，且与面/体项一起满足离散恒等式

$$\frac{d}{dt}\sum_j w_j y_j = -2k_c\sum_j w_j y_j + k_c y_N - \frac{h_m}{R}(y_N - C_\infty)$$

这正是移动域下的精确守恒式（由 \int_0^1 ξ\,\partial_t y|_\xi d\xi = -h_m(C_R-C_\infty)/R + k_c(C_R - 2\int_0^1\xi C d\xi) 推出），实测残差 **2.56×10⁻¹⁴**。

**时间**：**Crank–Nicolson（θ=0.5）**，前 3 步取后向 Euler（Rannacher 启动），内部步长 Δt = 5 s，报告层每 60 s 记录一次。非线性系数（ρ、c_p、k、D）在上一时间层取值（滞后系数），因此格式**对 Δt 一阶**；实测 6 h 表面值随 Δt 的序列为 0.5654344 (20 s)、0.5654216 (10 s)、0.5654349 (5 s)、0.5654412 (2.5 s)，Richardson 极限 0.5654476，取 Δt = 5 s 后剩余一阶误差约 10⁻⁵，低于报告精度。

**线性代数**：每步一次带状求解（scipy `solve_banded`），O(N)。

**报告映射（T1 口径）**：每个记录时刻先算 R(t)，列 \r_k = 0, 0.1, …, 1.9 cm 取 ξ = r_k/R(t) 处的三次样条值；**r_k > R(t) 的单元格留空**；末列"药材表面"取 ξ=1 的原生节点值。

**实现要点（两处容易写错的量纲，记录在案）**：
1. 能量方程除以 ρc_p 后，表面对流项在 ξ 度量下的系数是 h/(ρc_p·R)，**不是** h/R；写成 h/R 会把表面温度的响应放大 ρc_p 倍。
2. 格心基线的表面对流传导是串联电阻 (Δξ/2)R²/co + R/h_surface；其中 h_surface 在"除以 ρc_p"的度量下是 h/(ρc_p)（传质则是 h_m）。写错这两处会让烘干时长偏差 3% 以上、表面列偏差一个数量级。

## 5. 适用边界（必须随方法一并写入论文）

1. 结论以题目给定的 h_m、h 与附录4 经验式为条件；
2. 恒温段环境（14400 s 后 T\infty = 50 °C、C\infty = 0.05 kg/kg）为**人为设定的口径**，非实测；
3. 收缩假设各向同性且严格按附件2；质量方程取题目给定的 Fick 标准形式（ρ 不入质量方程），因此几何收缩在模型内**不是**质量汇；
4. 一维径向轴对称忽略端面轴向输运（52.6 h 内轴向水分渗透达数厘米/端，量级已量化）；
5. 数值方案由解析对照、移动边界一致性、网格/时间加密实验认证，而非先验论证；
6. 独立基线在表6 表面列的一致性水平为 4×10⁻⁴（其表面值由一阶半单元关系回算），主方法自身的网格收敛为 2.1×10⁻⁶。
