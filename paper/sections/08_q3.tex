\section{问题三：烘干时长的确定}

\subsection{问题分析与模型的建立}

\subsubsection{本问的判据}

问题三与问题二共用同一套模型，差别只在输出形态。
题目给出的干燥要求是全域各点都达到干燥标准，即\textbf{全域最大干基含水率}
降至 $0.15$~kg/kg 以下：

\begin{equation*}
  \max_{0\le r\le R}C(r,t)\le 0.15~\text{kg/kg}
\end{equation*}

烘干时长即为该条件首次满足的时刻，

\begin{equation*}
  t_{\mathrm{dry}}=\min\left\{t:\ \max_{0\le r\le R}C(r,t)\le 0.15~\text{kg/kg}\right\}
\end{equation*}

\subsubsection{控制点的确定}

需要留意的是判据针对“全域各处”，而由问题二的结果可知，
全域最大干基含水率始终出现在药材中心，故本问以中心点的含水率作为判据的量。

\begin{enumerate}[label=\protect\cnum{\arabic*}, leftmargin=2.6em, itemsep=2pt, topsep=3pt, parsep=0pt]
  \item 含水率的下降\textbf{自表面向中心推进}：靠表面的窄带最先变浅，
        中心区在很长时间内仍保持接近初值的高含水率，直到后期才整体变浅。
  \item 越接近烘干结束，整幅云图越趋于均匀，说明中心与表面的差别已被抹平——
        这是扩散控制的必然结果：内部浓度梯度被逐步抹平后，表面可带走的水分随之减少，
        含水率的下降自然越来越慢，因此烘干时长的后半段主要是“等待内部水分扩散到表面”。
\end{enumerate}

\subsection{数值检验与适用性分析}

\subsubsection{数值检验与收敛性}

本问的数值可信度由四类相互独立的证据确认，全部检验量汇总于表~\ref{tab:verify}。

\begin{enumerate}[label=\protect\cnum{\arabic*}, leftmargin=2.6em, itemsep=2pt, topsep=3pt, parsep=0pt]
  \item \textbf{网格加密}：网格由 $400$ 加密到 $800$，报告点上的最大差为 \qthreegridrefinementdiff。
  \item \textbf{时间加密}：内部步长由 $10$~s 减半到 $1$~s，烘干时长的变化为 \qthreetimerefinementdiff。
  \item \textbf{守恒性}：离散质量守恒的相对残差为 \qthreemassbalancerel，达到机器精度量级。
  \item \textbf{独立复算}：格心实现给出的烘干时长与本文方法相差 \qtwodryingtimespread，与问题二一致。
\end{enumerate}

\textbf{四类证据一致表明本问给出的烘干时长已达到网格与步长无关的水平。}
需要指出的是，本问的检验量比问题二更"苛刻"：问题二核对的是 $3$~h 内的温度与含水率，
本问核对的则是判据穿越时刻本身，因此上述差异都落在时间轴上。

\subsubsection{判据尾部平坦性的影响}

\textbf{烘干时长精确落在判据穿越时刻，而该时刻受判据尾部平坦性的影响较大}：
两套相互独立的实现之间的分歧（\qtwodryingtimespread）完全来自这一效应——
含水率曲线在判据附近近乎水平，极小的数值差异即可换来可观的时间差。

因此我们在引用烘干时长时同时给出该量级的不确定度，即烘干时长为 \qthreedryingtime，
其不确定度约为半分钟，不影响以小时为单位的结论。

\subsubsection{参数与口径灵敏度}

\steptitle{两类灵敏度对象}

灵敏度分析针对两类对象：一类是题目给定但数值本身带不确定性的参数（对流传质系数、
扩散系数、环境温度与环境水分浓度），另一类是建模过程中必须做出选择的设定（质量方程的读法）。
为使扰动方向的影响可见，对传质系数与环境水分浓度做了\textbf{双向扰动}，

\steptitle{三点归纳}

表~\ref{tab:sens} 与图~\ref{fig:sens} 给出的信息可以归纳为三点。

\begin{enumerate}[label=\protect\cnum{\arabic*}, leftmargin=2.6em, itemsep=2pt, topsep=3pt, parsep=0pt]
  \item \textbf{烘干时长对表面传质系数最不敏感}：$h_m$ 缩小与放大 $5\%$ 分别使时长变化
        \qtwosenshmminusfivepct 与 \qtwosenshmplusfivepct，两者量级相同、符号相反，
        说明该响应在 $\pm5\%$ 内近似线性，不存在单向放大。
        其原因仍在于干燥由内部水分扩散控制，传质 Biot 数约为 $20$，表面传质阻力不是瓶颈——
        把表面“擦得更干”并不能加快内部水分向外迁移的速度。
  \item \textbf{扩散系数与环境温度的影响依次增大}：$D$ 放大 $5\%$ 使时长变化 \qtwosensDplusfivepct，
        环境温度升高 $2$~$^\circ$C 变化 \qtwosensTinfplustwoC，两者都缩短时长。
  \item \textbf{环境水分浓度的影响最小}：$C_\infty$ 在 $0.045$ 与 $0.055$~kg/kg 两个方向的扰动
        分别带来 \qtwosenscinflow 与 \qtwosenscinfhigh 的变化，即恒温段浓度口径的不确定性可以忽略。
\end{enumerate}

由此得到一个对结论表述至关重要的判断：\textbf{主导烘干时长的不确定性不是题目给定的传质系数，
而是模型自身的口径}——质量方程改用湿基自洽式即使烘干时长变化 \qtwosensmassequationform，
其量级远大于表中任何一项参数扰动。

\steptitle{与问题一的对照}

与之形成对照的是问题一：预热段的表面值对传质系数较为敏感，放大 $5\%$ 即使表面含水率变化
\qonehmplusfivepctsurfaceshift，故该问的表面值只在题目给定值下成立。

\subsubsection{本问结论的适用范围}

本问的适用范围与问题二相同，另有两点需要说明。

\begin{enumerate}[label=\protect\cnum{\arabic*}, leftmargin=2.6em, itemsep=2pt, topsep=3pt, parsep=0pt]
  \item 烘干时长以题目给定的 $h_m$、$h$ 与附录 3 经验式为条件；恒温段环境
        （$50$~$^\circ$C、$0.05$~kg/kg）取附件 1 稳定段均值外延，属模型设定而非实测；
        质量方程取题目给定的 Fick 标准形式。
  \item 一维径向轴对称模型忽略了两端面的轴向输运；
        且本问结果是在\textbf{半径不变}的前提下得到的，而实际烘干过程中药材会随失水而收缩，
        这一效应是否可忽略将在第九章定量回答。
\end{enumerate}
