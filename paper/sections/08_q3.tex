\section{问题三：烘干时长的确定}

\subsection{问题分析与模型的建立}

\subsubsection{本问的判据}

问题三与问题二共用同一套模型，差别只在输出形态。
题目给出的干燥要求是全域各点都达到干燥标准，即\textbf{全域最大干基含水率}
降至 $0.15$~kg/kg 以下：

\begin{equation*}
  \max_{0\le r\le R}C(r,t)\le 0.15~\text{kg/kg}
\end{equation*}

烘干时长即为该条件首次满足的时刻，

\begin{equation*}
  t_{\mathrm{dry}}=\min\left\{t:\ \max_{0\le r\le R}C(r,t)\le 0.15~\text{kg/kg}\right\}
\end{equation*}

\subsubsection{控制点的确定}

需要留意的是判据针对“全域各处”，而由问题二的结果可知，
全域最大干基含水率始终出现在药材中心，故本问以中心点的含水率作为判据的量。

\end{enumerate}

\subsection{数值检验与适用性分析}

\subsubsection{数值检验与收敛性}

本问的数值可信度由四类相互独立的证据确认，全部检验量汇总于表~\ref{tab:verify}。

\begin{enumerate}[label=\protect\cnum{\arabic*}, leftmargin=2.6em, itemsep=2pt, topsep=3pt, parsep=0pt]
  \item \textbf{网格加密}：网格由 $400$ 加密到 $800$，报告点上的最大差为 \qthreegridrefinementdiff。
  \item \textbf{时间加密}：内部步长由 $10$~s 减半到 $1$~s，烘干时长的变化为 \qthreetimerefinementdiff。
  \item \textbf{守恒性}：离散质量守恒的相对残差为 \qthreemassbalancerel，达到机器精度量级。
  \item \textbf{独立复算}：格心实现给出的烘干时长与本文方法相差 \qtwodryingtimespread，与问题二一致。
\end{enumerate}

\textbf{四类证据一致表明本问给出的烘干时长已达到网格与步长无关的水平。}
需要指出的是，本问的检验量比问题二更"苛刻"：问题二核对的是 $3$~h 内的温度与含水率，
本问核对的则是判据穿越时刻本身，因此上述差异都落在时间轴上。

\subsubsection{判据尾部平坦性的影响}

烘干时长即为判据的穿越时刻，因此它继承了判据尾部的平坦性：
判据附近中心含水率的下降速率仅约 $8\times10^{-3}$~kg/kg/h，
而本文方法的网格与步长误差在 $10^{-7}$~kg/kg 量级，
落到时间轴上即放大为 \qtwodryingtimespread 的差别，而非方法本身的精度。
故本问给出的烘干时长为 \qthreedryingtime，其时间不确定度约为半分钟，不影响以小时为单位的结论。

\subsubsection{参数与口径灵敏度}

\steptitle{两类被扰动的量}

灵敏度分两类。第一类是工艺条件类的量：对流传质系数 $h_m$、有效水分扩散系数 $D$、
环境温度 $T_\infty$ 与环境水分浓度 $C_\infty$；第二类是模型自身选定、题目未给的口径，
即质量方程的读法。
$h_m$ 与 $C_\infty$ 各取正负两个方向，原因不同：$h_m$ 取 $\pm5\%$，
用于判断该响应是否近似线性、有无单向放大；
$C_\infty$ 的 $0.045$ 与 $0.055$~kg/kg 是两个\textbf{并列的设定}而非增减量——
它们分别是附件 1 稳定段的水分浓度下限与上限，两种取值都可能代表真实烘房，
故必须各算一次。$D$ 与 $T_\infty$ 只升不降：题目给出的是经验式的基准值，
提高扩散能力是本文要回答的工艺问题，反向取值不对应任何设问，反向算例也不改变结论。
结果见表~\ref{tab:sens}，图~\ref{fig:sens} 是同一组数据的条形形式。

\steptitle{归纳}

表中四项工艺条件的影响可分为一强一弱两组。
$D$ 放大 $5\%$ 使时长变化 \qtwosensDplusfivepct，环境温度升高 $2$~$^\circ$C 变化
\qtwosensTinfplustwoC，两者都缩短时长，是影响较强的一组。
$h_m$ 缩小与放大 $5\%$ 分别为 \qtwosenshmminusfivepct 与 \qtwosenshmplusfivepct，
量级相同、符号相反，说明该响应在 $\pm5\%$ 内近似线性、不存在单向放大；
$C_\infty$ 取 $0.045$ 与 $0.055$~kg/kg 时分别为 \qtwosenscinflow 与 \qtwosenscinfhigh，
两个方向一升一降。这两个量同属影响最弱的一组，改变表面条件并不能加快内部水分向外迁移，
原因见问题二的干燥控制机制分析。

真正需要声明的是第二类量：\textbf{主导烘干时长的不确定性不是题目给定的参数，
而是模型自身的口径}——质量方程改用湿基自洽式即使时长变化 \qtwosensmassequationform，
其量级远大于表中任何一项参数扰动。与之形成对照的是问题一：
预热段的表面含水率对 $h_m$ 敏感，放大 $5\%$ 即变化 \qonehmplusfivepctsurfaceshift，
故该问的表面值只在题目给定值下成立。
